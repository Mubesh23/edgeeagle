# ADR — Expo React Native Mobile

**Status:** Proposed  
**Date:** 2026-09-22

## Context

Strong cross-platform developer velocity while allowing mobile-specific UX.

## Decision

Use Expo/React Native/TypeScript for iOS and Android while sharing contracts/tokens/utilities with the monorepo.

## Consequences

Do not force desktop components into mobile.
