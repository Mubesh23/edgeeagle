# @edgeeagle/api-client

Typed API transport for future web, mobile, and MCP consumers. Generated types
come from FastAPI OpenAPI; the small maintained entry point creates an
openapi-fetch client. It owns no probabilities, pricing, risk, or business state.

Future workspace consumers depend on `@edgeeagle/api-client` via `workspace:*`.
Build with `scripts/build` before using its ESM exports. For example:

```ts
import { createApiClient } from "@edgeeagle/api-client";

const client = createApiClient({ baseUrl: "http://127.0.0.1:8000" });
const { data, error, response } = await client.GET("/health");
```

The caller supplies the URL and may inject `fetch` through the options. There
are no embedded credentials, global client instance, automatic retries, or network
calls at import time. Fetch/Request/Response support must be supplied by the host
runtime. Web, Expo, and MCP runtime integration will be verified when those apps
land. TypeScript types do not perform runtime response validation.

Never edit `src/generated/schema.ts`; run root `scripts/generate-contracts`.
Root validation checks generation drift, strict client typechecking (including
invalid paths/methods), and offline request/HTTP-error tests with injected fetch.
Build output under `dist/` is ignored and regenerated by TypeScript.

See [contract generation](../../../contracts/README.md) and
[openapi-fetch documentation](https://openapi-ts.dev/openapi-fetch/).
